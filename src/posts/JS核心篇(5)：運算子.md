## 三元運算子
* 問號前面是判斷的值，若**成立**就會回傳分號前面的值，若**不成立**就會回傳分號後面的值。
```js
const isApple = true;

function sayFruit() {
  console.log(isApple ? '蘋果' : '香蕉');
}

sayFruit(); //蘋果
//判斷式 ? 表達式1 : 表達式2 ;
//(判斷式)成立/不成立，執行{表達式1}/{表達式2}。
```
